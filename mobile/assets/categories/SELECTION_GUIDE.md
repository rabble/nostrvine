# Category Emoji Selection Guide

Current defaults are marked with **[DEFAULT]**. To swap, rename the desired
option file (from `options/`) to replace the current SVG.

All emoji are from [OpenMoji](https://openmoji.org/) (CC BY-SA 4.0).

Preview any option at: `https://openmoji.org/library/emoji-{UNICODE}/`

## How to swap an option

```bash
# Example: change Music from guitar to headphones
cp options/music_headphones.svg music.svg
```

Then rebuild the app. The `options/` folder is NOT bundled into the app binary.
